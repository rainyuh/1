# 场景分析 · 雨夜公交站

## 1. 场景

深秋的上海，晚上十点半，一场持续的冷雨。街角的公交站只剩一盏广告灯箱亮着，站台顶棚把雨切成两种声音：头顶密集的敲击，和檐口成串滴落的水珠。马路上偶有车辆碾过积水，轮胎带起一片水雾；远处高架的车流像一条低沉的河。站牌后的便利店自动门开合，传出短暂的提示音。等末班车的人把伞收拢，跺掉鞋上的水，站台顶棚下的回声让每一次动作都显得很近。

**听者位置**：站在站台顶棚下，背对广告灯箱，面向马路。这个位置很关键——头顶是近场雨打顶棚，外面是中远场雨打路面和车流，两种雨声天然分层。

## 2. 为什么选这个场景

1. **基底/事件分离清楚**：雨打顶棚、雨打路面、远处车流是持续层；车过积水、门铃、电瓶车喇叭、公交气刹是间断层。
2. **Positioning 有内容**：车从远处驶近再远去、门铃在背后、电瓶车在便利店与站台之间、公交从前方进站，方位和距离都有变化。
3. **中国城市细节**：公交站牌、便利店门铃、电瓶车喇叭，比通用“rain ambience”更有辨识度。
4. **素材可获取**：雨、车、门铃、公交都能找到真实录音，也可以用手机补录。

## 3. 声音层次

| 层 | 声音 | 作用 | Wwise |
|---|---|---|---|
| 近场基底 | 雨打站台顶棚 | 建立“站在棚下”的亲密感 | Loop Infinite，2D |
| 远场基底 | 雨打湿沥青 + 远处车流 | 建立街道空间和城市纵深 | Loop Infinite，比近场低 6 dB |
| 事件层 | 车过积水 ×3 | 道路方向、距离变化 | Random Container + Attenuation |
| 事件层 | 便利店门铃 | 站牌后方的店门细节 | 单独 Sound SFX + 远距离衰减 |
| 事件层 | 电瓶车喇叭 | 便利店与公交站之间的非机动车道 | 单独 Sound SFX + 方位 |
| 事件层 | 公交气刹 + 门 | 场景叙事点：末班车进站 | 单独 Sound SFX + 中距离衰减 |

## 6. 照片建议

- 站台全景 1 张：能看到顶棚、站牌、广告灯箱和湿路面。
- 细节 1 张：顶棚滴水、地面积水或雨打顶棚的特写。
- 手机夜景模式，擦干净镜头；避免路人正脸；上传前去掉 EXIF/GPS。
- 如果没有合适的实拍，可以用一张有明确许可的参考图，并在 README 标注来源和许可。
